# Inventory Broadly and Verify Providers Explicitly

The project will maintain a broad inventory of Web Products inspired by the public site coverage demonstrated in reference projects, while implementing and live-verifying only ChatGPT, Doubao, and DeepSeek in the first release. Every provider carries a support tier of verified, experimental, or planned; Zotero GPT Connector's All Rights Reserved userscript may inform independent research, but its selectors, parsers, upload strategies, and adapter code must not be copied, and no provider is called supported without current acceptance evidence.
