# Use Web Products as Primary Model Backends

The Gateway Node exists to make authenticated Web Products the primary model backends for Codex, Claude Code, and other Agent Clients through Responses and Messages. An MCP consultation surface is deferred: exposing a Web Product as a subordinate tool would still require another primary model and would not provide the native streaming, tool-call, tool-result, cancellation, and task lifecycle that define this product.
